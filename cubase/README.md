# Совместное сочинение в Cubase

Статус: начальный порядок работы; универсальный шаблон проекта ещё не подготовлен.

1. Уточнить назначение музыки и выбрать короткий участок для пробы.
2. Создать отдельный проект. Если есть видео, подключить его и один источник голоса,
   проверить синхронизацию, частоту кадров и конец материала.
3. Хранить смысловые ориентиры во времени, музыкальные петли — в тактах.
4. Выбрать несколько звуков для нужных ролей. Сравнивать одинаковый рисунок при
   сопоставимой громкости; фиксировать точные названия одобренных пресетов в проекте.
5. Собирать петлю на 2–8 тактов: гармоническая опора, короткий мотив, ритм по необходимости.
   Сравнивать по два варианта, меняя один параметр.
6. Проверять в контексте назначения. Для фона — разборчивость речи и утомляемость повтора.
7. Сохранять выбранный вариант, затем делать разреженную и более активную версии.
8. Разворачивать форму после успешной короткой пробы; проверять весь результат перед экспортом.

Темп, тональность, стиль и инструменты выбираются для новой задачи. Прошлые версии
не становятся требованиями автоматически. Объяснять музыкальные решения на выбранном
материале: ноты, ступени, состав аккордов, напряжение и разрешение.

Для будущего живого исполнения рано проверять диапазон, аппликатуры и удобство темпа.
Разные партии можно записывать отдельными дублями. Не считать MIDI реалистичной гитарой
только по названию пресета. Подключение луп-педали зависит от её модели и схемы записи.

Названия файлов, локальные настройки Cubase, конкретные пресеты, согласованные решения
и результаты прослушивания записывать в папке текущего музыкального проекта.
