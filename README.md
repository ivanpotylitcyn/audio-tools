# audio-tools

Личная мастерская инструментов для сочинения музыки, записи и работы в Cubase.
Подходит для сопровождения видео и самостоятельных песен. Работает независимо
от видеомонтажа и учебных хранилищ.

Здесь — общие инструкции, проверенные шаблоны и инструменты. Конкретные композиции,
таймкоды, аудиозаписи, медиа, MIDI и проекты Cubase остаются в папках музыкальных проектов.
Локальные пути подключения задаются проектами, а не этим репозиторием.

## Состояние

Начальный каркас. Реализованных CLI-инструментов и проверенных шаблонов пока нет.
Cubase используется вручную. Сначала обкатываем короткие музыкальные пробы.
Зависимости и специальные окружения не устанавливались.
